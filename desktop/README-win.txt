마감 역산 일정표 · PC 위젯 (윈도우)

[처음 실행]
1. 이 압축 파일을 풀고, 폴더를 지우지 않을 곳(예: 문서 폴더)에 둬요.
2. 폴더 안 DeadlinePlanner.exe 를 더블클릭해요.
3. "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] → [실행]을 눌러요.
   (개인이 만든 프로그램이라 서명이 없어서 처음 한 번 뜨는 창이에요.)

[쓰는 법]
- 전체 창과 함께 오른쪽 위에 D-day 위젯이 떠요. 위젯 윗줄을 잡고 끌면 옮겨져요.
- 위젯 아래쪽 다른 일정을 누르면 그 일정의 D-day가 크게 보여요.
- 핀 버튼: 켜면 다른 창보다 항상 위에 떠 있어요. 다시 누르면 풀려요.
- × 를 눌러도 꺼지지 않고 숨기만 해요. 작업 표시줄 오른쪽 아래 트레이(^) 아이콘을 누르면 다시 떠요.
- 컴퓨터를 켜면 위젯이 자동으로 떠요. 트레이 아이콘 우클릭 → "컴퓨터 켤 때 위젯 자동 실행"으로 끌 수 있어요.
- 완전히 끄려면 트레이 아이콘 우클릭 → 종료.

[알아 둘 것]
- 폴더를 다른 곳으로 옮겼다면 exe를 한 번 다시 실행해 주세요. 자동 실행 위치가 새로 잡혀요.
- 이 프로그램의 일정은 웹사이트 일정표와 저장 공간이 달라요. 옮길 땐 [백업 받기] → [불러오기]를 써 주세요.
